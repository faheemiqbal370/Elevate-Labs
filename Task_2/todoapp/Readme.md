#  To-Do List Web App

A simple and responsive To-Do List app built with vanilla HTML, CSS, and JavaScript.

---

##  Project Structure

todo-app/
├── index.html    → App structure
├── style.css     → Styling and layout
├── app.js        → All functionality
└── README.md     → Documentation

---

##  Features

- Add tasks by clicking button or pressing Enter
- Mark tasks as complete (strikethrough effect)
- Delete tasks with smooth fade-out animation
- Live task counter
- Empty state message when no tasks exist
- Fully responsive on mobile

---

##  Built With

- HTML5, CSS3, Vanilla JavaScript
- Google Fonts (Poppins)
- VS Code + Live Server

---

##  How to Run

1. Open folder in VS Code
2. Right-click `index.html`
3. Select **"Open with Live Server"**

---

##  Concepts Practiced

- DOM manipulation
- Event listeners
- CSS class toggling
- Input validation
